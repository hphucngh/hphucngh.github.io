glossary

A running glossary of the technical terms used across the posts.

Attention & cache

KV cache #

Cached Key/Value tensors for already-processed tokens, so attention doesn't recompute them on every generation step.

Bộ nhớ đệm lưu Key/Value của các token đã xử lý, để attention không phải tính lại từ đầu mỗi bước.

related: gqamlapaged-attention

MHA #

Multi-Head Attention — the classic design where every query head has its own KV head; the largest cache.

Multi-Head Attention cổ điển: mỗi query head có KV head riêng → cache lớn nhất.

related: gqamqa

GQA #

Grouped-Query Attention — several query heads share one group of KV heads, cutting the KV heads to cache roughly 8×.

Grouped-Query Attention: nhiều query head chia sẻ chung một nhóm KV head → giảm số KV head phải cache (~8×).

related: mhamqakv-cache

MQA #

Multi-Query Attention — a single KV head shared by all query heads; the smallest cache, but a noticeable quality drop.

Multi-Query Attention: chỉ 1 KV head cho tất cả query head → cache nhỏ nhất, nhưng chất lượng giảm.

related: gqa

MLA #

Multi-head Latent Attention — compresses K, V into a latent space before caching; more efficient than GQA, more complex.

Multi-head Latent Attention: nén K, V xuống không gian latent trước khi cache — hiệu quả hơn GQA, kiến trúc phức tạp hơn.

related: gqakv-cache

Serving

PagedAttention #

Allocates the KV cache in small non-contiguous blocks (~16 tokens), borrowing the OS paging idea; frees blocks the moment a request finishes. (vLLM)

Cấp phát KV cache theo block nhỏ (~16 token), non-contiguous, mượn ý tưởng paging của hệ điều hành (vLLM).

related: continuous-batchingprefix-caching

Continuous batching #

Slots a new request into a freed spot the instant one finishes, keeping the GPU busy instead of waiting for the whole batch.

Nạp request mới vào slot trống ngay khi có request xong, thay vì chờ cả batch xong.

related: paged-attention

Prefix caching #

Computes and caches a shared prefix (e.g. a system prompt) once, then reuses it across requests.

Nhiều request chung system prompt thì chỉ tính và cache phần đó một lần, dùng chung.

related: kv-cache

Sliding window #

Keeps only the last N tokens, giving a fixed cache regardless of context length; good for chat, bad for document processing.

Chỉ giữ N token gần nhất, cache cố định bất kể context dài bao nhiêu; hợp chat, không hợp document processing.

related: token-eviction

Token eviction #

Drops tokens from the cache by a heuristic (attention sink, cumulative attention score, group compression) for an effective context longer than the physical cache.

Bỏ bớt token khỏi cache theo tiêu chí (attention sink, điểm attention tích lũy, nén nhóm token).

related: sliding-window

Architecture

MoE #

Mixture-of-Experts — only a subset of experts is active per token, but all expert weights must stay in VRAM (any token can route to any expert).

Mixture-of-Experts: chỉ một phần expert active mỗi token, nhưng toàn bộ expert weights phải nằm trong VRAM.

related: kv-cache

Speculative decoding #

A small draft model guesses ahead while a large verifier checks in parallel; each model needs its own KV cache.

Model nhỏ (draft) đoán trước, model lớn (verifier) kiểm tra song song — mỗi model cần cache riêng.

related: kv-cache

Inference phases

Prefill #

The phase that processes the whole input in parallel; compute-bound.

Pha xử lý toàn bộ input, chạy song song, giới hạn bởi compute.

related: decode

Decode #

The phase that generates output one token at a time, sequentially; memory-bandwidth-bound.

Pha sinh output từng token, tuần tự, giới hạn bởi băng thông bộ nhớ.

related: prefill
