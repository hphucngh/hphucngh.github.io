| Thuật ngữ (Anh / Việt)                                    | Định nghĩa tóm tắt                                                                                                                          |
| :--------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------- |
| **Machine Learning (Học máy)**                             | Quá trình huấn luyện một mô hình phần mềm học hỏi từ dữ liệu để đưa ra dự đoán hoặc quyết định thay vì được lập trình các quy tắc rõ ràng. |
| **Supervised Learning (Học có giám sát)**                  | Huấn luyện mô hình dựa trên tập dữ liệu đã có sẵn nhãn (đáp án chính xác).                                                                 |
| **Unsupervised Learning (Học không giám sát)**             | Huấn luyện mô hình tìm ra các mẫu và cấu trúc ẩn trong tập dữ liệu không có nhãn.                                                          |
| **Reinforcement Learning (Học tăng cường)**                | Mô hình (tác nhân) học cách hành động trong một môi trường để tối đa hóa phần thưởng nhận được.                                              |
| **Batch / Online Learning (Học theo lô / Trực tuyến)**    | Học theo lô huấn luyện trên toàn bộ dữ liệu offline. Học trực tuyến huấn luyện mô hình tăng dần khi có dữ liệu mới.                         |
| **Model (Mô hình)**                                       | Cấu trúc toán học xử lý dữ liệu đầu vào và trả về dự đoán/kết quả đầu ra.                                                                  |
