| Thuật ngữ (Anh / Việt)                                  | Định nghĩa tóm tắt                                                                                                                    |
| :------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------- |
| **Linear Regression (Hồi quy tuyến tính)**              | Kỹ thuật thống kê dùng để dự đoán một giá trị số liên tục bằng cách tìm mối quan hệ tuyến tính giữa các biến.                         |
| **Logistic Regression (Hồi quy logistic)**              | Mô hình dự đoán xác suất (từ 0 đến 1) của một phân loại nhị phân bằng cách dùng hàm sigmoid.                                          |
| **Decision Tree (Cây quyết định)**                      | Mô hình dự đoán dạng cây với các nút là điều kiện kiểm tra (test) dẫn đến các lá chứa dự đoán cuối cùng.                               |
| **Random Forest (Rừng ngẫu nhiên)**                     | Một tập hợp (ensemble) của nhiều cây quyết định, mỗi cây được huấn luyện bằng một mẫu dữ liệu hoặc nhóm đặc trưng ngẫu nhiên.         |
| **Gradient Boosting**                                    | Kỹ thuật kết hợp tuần tự các mô hình yếu (như cây quyết định), mô hình sau tối ưu hóa để sửa lỗi của mô hình trước.                    |
| **K-Means Clustering (Phân cụm K-Means)**               | Thuật toán học không giám sát gom dữ liệu thành K cụm dựa trên khoảng cách tới các tâm điểm (centroids).                               |
| **SVM (Máy học Vectơ hỗ trợ)**                          | Mô hình tìm ra siêu phẳng phân tách các lớp dữ liệu với lề (margin) rộng nhất có thể.                                                 |
| **PCA (Phân tích thành phần chính)**                    | Kỹ thuật giảm chiều dữ liệu bằng cách chiếu dữ liệu xuống không gian chiều thấp trong khi vẫn bảo toàn phương sai lớn nhất.            |
